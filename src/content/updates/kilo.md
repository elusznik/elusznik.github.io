There is a new stealth model available in Kilo Code called Spectre. It is supposedly a state-of-the-art model from one of the top 10 labs in the world, with rumors online of it being **Mistral Large 3**. The context windows is 256k tokens with 8k tokens of output per step. There is currently no image input or multimodal support, but we can "expect updates soon". There is **no usage cap**.
